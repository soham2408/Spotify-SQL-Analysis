# Spotify SQL Analysis

## Overview

This project performs an end-to-end SQL analysis of over **586,000 Spotify tracks** using **MySQL Workbench**. The objective is to extract meaningful business insights from music data while demonstrating practical SQL skills commonly used in data analytics.

---

## Dataset Information

- Dataset: Spotify Tracks Dataset
- Total Records: ~586,000
- Total Columns: 20
- Database: MySQL
- Tool: MySQL Workbench

---

## Skills Demonstrated

- SQL Queries
- Filtering & Sorting
- Aggregate Functions
- GROUP BY & HAVING
- CASE Statements
- Window Functions
- Common Table Expressions (CTEs)
- Subqueries
- String Functions
- Views
- Query Optimization

---

## Business Questions Answered

- How many tracks exist in the dataset?
- Which artists have released the most songs?
- Which songs are the most popular?
- How has music production changed over time?
- Are explicit songs more common?
- Which tracks are the most danceable?
- Which songs have the highest energy?
- What are the overall trends in Spotify music?
